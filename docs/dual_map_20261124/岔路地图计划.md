## 一、底层根因深度复盘：为什么 `fork_06 / 11 / 12` 笔直冲出蓝垫，而普通 90° 弯（`fork_13`）不会？

1. **定性真相：冲出界处不是“单行道 90° 墙壁折弯”，而是无标识的 `┤` 丁字垂直汇合口**
   - `fork_13` 终点 `END` 前（`t=69.0s`）真正的单行道 90° 左折弯外沿黑边呈斜切对角线（5 切片上沿落差 `spread = 83 px`，全宽横贯行仅 `1` 行），原算法依靠单侧边界收缩（`error = -0.71`）自行平滑拐过。
   - `fork_06 / 11 / 12` 选右支路（数字 `4`）进入内侧捷径横梁，末端 90° 垂直撞上外环主干道：**左转 90° = 逆行（直接判本轮无效）**，**右转 90° = 唯一合法顺行方向（经红色禁行区、第 3 条黄线去 `END`）**。
2. **源码三阶段死锁机制（`line_follower_node.cpp` `find_band_run`）**
   - 距前墙 `55~18 cm` 长达 `1.8s` 内，横向主干道同时铺满 `far_band` 与 `near_band` 全宽 `[0, 639]`，几何中点恒为 `(0+639)/2 = 319.5`（`near_error = 0, far_error = 0, curve_level = 0`），控制器满速 `0.30 m/s` 零转向直撞前墙；等 `<18 cm` `far=None` 时已小于物理最小转弯半径 `30 cm`，且 `fork_12` 绕锥后车头微偏左使局部白路反而左宽右窄（指向逆行侧），局部启发式必误判。

## 二、核心方案与两轮回放调优结论

### 1. `┤` 丁字汇合口三层正交顺行闭环并线（`enable_tjunction_merge: true`，8 包 8,481 帧 `0` 误判）
- **几何层**：在桥接黄线的车底种子 8 连通道路掩膜 `connected_road` 上检验 5 切片道路上沿：`min_yt >= 0.23H`（距墙 `~55 cm` 提前触发）、水平直墙落差 `spread <= 0.10H`（丁字口实测 `5~8 px`；所有单行道 90° 弯与 180° 大拱弯 `spread = 34~135 px` 完全无交集）、墙下 `>=94%` 全宽独立扫描线 `frows >= 55` 行（连续 `3` 帧确认）。
- **拓扑层**：跟踪 `yellow_count == 2` 段首次 `/cmd_vel_detection` 转向：仅右切内支路（`fork_06/11/12`, `ang ≈ -0.74`）时布防 `T_MERGE_ARMED`，走左外环（`fork_13`, `ang = +0.18`）自动识别为 `T_MERGE_OUTER_BRANCH` 绝不布防。
- **执行与闭环退出**：触发后以 `v = 0.16 m/s, w = -1.20 rad/s`（等效半径约 `13 cm`）严格按顺行方向右转；转过 `0.35s` 保底角后，一旦顶部前视道路重新敞开（`upper_road_ratio >= 0.12` 且 `frows < 20`）或达 `1.15s` 安全上限即闭环交回 PD 巡线。
- **回放验证**：`fork_06`（`30.89s`）、`fork_11`（`39.64s`）、`fork_12`（`36.58s`）全部在距墙 `~55 cm` 处精准触发顺行右转；`fork_13` 全程 `1,328` 帧（含大拱弯、急 S 弯、终点前 90° 折弯）触发 **`0` 次**。

### 2. 单行道急弯动态远端预瞄与纵向质心解耦（回放关键修正！）
- **回放发现的跨模块耦合问题**：初版开启 `enable_curve_preview_steering` 拉大 `far_weight` 时，同步把发布的 `/line_follower/centroid.y` 从 `0.646` 拉高到了 `0.619`，导致 `fork_13` 分岔口右侧出界数字 `2`（`cy <= 0.61`）提前触发转向而漏掉了左侧高分数字 `4`！
- **解耦修正**：`target_x` 使用动态预瞄权重 `far_weight`（最高 `0.50`）提前入弯，而 `target_y` 固定保持 `0.70 * near_y + 0.30 * far_y` 纵向基准不变，同时保留“全图有效视野 `[0.48, 0.72]` 先取最大数字再判对齐（`tol = 0.012, conf >= 0.35`）”。
- **修正后回放结果**：`fork_06 / 11 / 12 / 13` 全部 `8 / 8` 次数字选择 100% 精准命中 `[5, 4]`，且单行道急弯（如 `fork_13` `t=66.5s`）入弯转向力从 `+0.63` 提升至 `+0.94 rad/s`、车速降至 `0.17 m/s`，不再贴黑线；终点停稳后误触发降为 **`0` 次**。

### 3. 汇合口下游镂空红色禁行区近端优先与避让增益调优
- **回放发现的问题**：`fork_13` `t=52.0~53.6s` 处脚下红色禁行区（`bottom=0.82`）与 2 米外远端红锥（`bottom=0.14`）同框，原代码无条件选 `cone` 导致 44 帧禁行区被遮蔽了 37 帧；且初版 `red_line_soft_yaw: 0.42` 放大后达 `-1.18 rad/s` 偏猛。
- **修正与调参**：改为按距离车头更近者优先（`line_bottom >= cone_bottom - 15`），并将 `red_line_soft_yaw` 调优至 **`0.28`**（`red_line_speed: 0.17`）。复测 `fork_13` 连续稳定检出 **44 帧**完整禁行区并柔和右绕，场边红色笔记本电脑（`t=66.5s`）**`0` 误检**。
